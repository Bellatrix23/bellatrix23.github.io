# 📚 theBookshelf

**theBookshelf** is a simple and interactive web application that allows users to manage a catalogue of their favorite books. Users can add, edit, and delete books, write reviews, and rate them. This project was developed as part of a task at HyperionDev, utilizing session storage to persist book data during the user's session.

## Project Overview 📖

The Bookshelf provides users with a cosy corner for their reading lists, reviews, and ratings. The application enables users to add details about their favorite books and manage their collection through an easy-to-use interface. The project demonstrates the use of **session storage**, allowing the application to temporarily store data for the duration of a session.

## Features ✨

- **Add Book Information**: Users can input details about books, including the author, title, genre, review, and rating.
- **View Book List**: All the books added by users are listed dynamically on the webpage.
- **Edit Book Information**: Users can easily edit any book details, which updates the catalogue in real-time.
- **Delete Book Information**: Users can remove books from their collection with a single click.
- **Rate Books**: Users can rate each book on a scale of 1 to 10.

## Technologies Used 🛠️

- **HTML5**: For structuring the content on the webpage.
- **CSS3**: For styling and designing the layout of the webpage.
- **JavaScript**: For dynamic interactions, including form handling, session storage management, and real-time updates to the book list.
- **Session Storage**: Used to store book data for the duration of the user's session, ensuring no permanent storage is needed.

## Getting Started 🚀

To get started with this project on your local machine, follow these steps:

1. **Clone the repository**:
    ```sh
    git clone https://github.com/Bellatrix23/theBookshelf.git
    ```
2. **Navigate to the project directory**:
    ```sh
    cd theBookshelf
    ```
3. **Open the `index.html` file** in your web browser to view the application.

## Usage 📋

1. **Adding a Book**: Fill in the form with the book details (author, title, genre, review, and rating), then click the "Add Book" button to add it to the list.
2. **Viewing Books**: All added books will appear dynamically on the page, displayed below the form.
3. **Editing a Book**: To modify a book’s information, click the "Edit" button next to the book, update the form fields, and the changes will be saved.
4. **Deleting a Book**: To remove a book, simply click the "Delete" button next to the book you want to remove, and it will be deleted from the list.

## Project Structure 📂

- `index.html`: Contains the HTML structure for the webpage, including the form for adding books and the display area for the book list.
- `styles.css`: Manages the styling for the webpage, including layout, form elements, and animations.
- `script.js`: Contains the JavaScript functionality to handle form submissions, session storage, and the dynamic display of books.
- `booklogo.jpg`: The logo image displayed at the top of the page.
